# Snake Arena Online (2D, HTML5 Canvas + Node.js + Socket.IO)

## Honest notes first
- **Strictly 2D.** No Three.js/Babylon/3D. I used plain **HTML5 Canvas** (allowed by your brief) instead of Phaser, so there is no big library to download.
- **No external assets are used.** I could not download files from Kenney/OpenGameArt/itch.io in my environment, and I will not invent URLs or licenses. All graphics (snakes, eyes, food, background, UI) are drawn by code, and sounds are generated by WebAudio. So the asset table is empty (see section C).
- **Bots are labeled `[BOT]`** so nobody mistakes them for real players. Real players always connect through the server.
- I could not run `npm install` or test with real phones here. The code is syntax-checked only. Test locally first (section D).

## Folder structure
```

  README.md
```

## D. Test locally (on your PC)
1. Install Node.js (LTS) from https://nodejs.org (it installs `node` and `npm`).
2. Open a terminal in the `server` folder: `cd snake-io/server`
3. `npm install` : downloads Socket.IO into `node_modules` and copies `socket.io.min.js` into `client/`.
4. `npm start` : runs `node server.js` (starts the server on port 3000).
5. Open http://localhost:3000 in your browser. Enter a name, press PLAY. Controls: mouse or WASD/arrows to steer, Space or click to boost.
6. Open the same address in a second tab: both snakes appear in the same room.

## E. Free server deployment (Render.com example)
Free tiers change, so check the current limits on the host's site. Render's free web service supports WebSockets but **sleeps after inactivity** (first connection can take about a minute to wake) and has monthly limits.
1. Put the whole `snake-io` folder on GitHub (create a repository, upload the files; do not upload `node_modules`).
2. On render.com: New > Web Service > connect the repo.
3. Settings: **Root Directory** `server`, **Build Command** `npm install`, **Start Command** `npm start`, instance type **Free**.
4. Deploy. You get a URL like `https://my-snake.onrender.com`. Open `/health` on it: it should show `ok`.

## H. Where the server URL goes
Open `client/socket-client.js` and change the single line:
```js
const SERVER_URL = "YOUR_SERVER_URL";   // becomes "https://my-snake.onrender.com"
```
Use `https://` (Android blocks plain http in many cases). Leave it as `YOUR_SERVER_URL` only for local testing from http://localhost:3000.

## F. APK conversion
1. Run `npm install` once so `client/socket.io.min.js` exists, and set `SERVER_URL` (above).
2. Zip the **contents** of the `client` folder (`index.html` must be at the zip root).
3. Upload that zip to your HTML-to-APK converter, set orientation to landscape, build, install the APK.

## I. What goes inside the APK
`client/index.html`, `style.css`, `game.js`, `socket-client.js`, `socket.io.min.js` (plus `assets/` if you add any later). No Node.js is needed inside the APK.

## J. What goes on the online server
Only the `server/` folder (`server.js`, `package.json`, `copy-client.js`). The client files are optional there (the server will also serve them if present, handy for testing).

## G. Two-phone test
1. Deploy the server, set `SERVER_URL`, build and install the APK on both phones (or open the website on both).
2. Put both phones on different networks if you like (Wi-Fi vs mobile data). Press PLAY on both.
3. Both should show the same Room number, "Room 1001 (2 players)", and you should see each other's snake move. Bots fill empty slots up to 8 total and leave as humans join.

## Network events (client and server must match)
`join` {name, skin} > `joined` {id, room, w, h} · `input` {a, b} > `state` (20/sec, only nearby snakes/food) · `died` {score, by}. Respawn = send `join` again.

## Commands explained
- `cd server` : go into the server folder.
- `npm install` : downloads the libraries listed in package.json.
- `npm start` : starts the server (same as `node server.js`).
